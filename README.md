# NOVA · AI Banking Agent

通过自然语言查询银行资料、准备业务任务，并在本人确认和风险分级验证后办理模拟银行业务。项目面向银行AI智能体赛题，提供统一Web工作台；不连接真实银行或真实支付。

> 全部账户资金、交易、商户与短信通道为比赛模拟。公开基金资料及净值有独立来源和日期；模拟执行成功不代表真实金融收益。完整AI体验需要配置可用的DeepSeek API。

## 项目解决的问题

把分散的银行入口变成“表达需求—查看任务—本人核对—执行—核对结果”的统一流程。用户既可以让NOVA理解模糊表达、补充上下文和规划多目标任务，也可以在工作台手动办理；人工接管保留已有输入和操作编号。模型负责理解和规划，银行服务核验身份、金额、资格、版本及授权，不能把模型文字当作交易凭证。

## 场景与当前能力

| 赛题场景 | 当前可体验的能力 | 需要区分的边界 |
|---|---|---|
| 智能转账 | 按联系人／手机号准备转账，多轮修改，单次定时转账，AA收款及原结果核对 | 转账须本人确认，达到红色条件须MFA；不是完整周期转账产品 |
| 账单分析 | 月度／年度统计、分类和变化追溯、异常核对、预算与订阅关联查询 | 新库默认无历史流水；没有数据时如实显示，需先生成模拟流水再体验变化 |
| 理财操作 | 本人风险评估、整体规划、类别／名称／代码候选、详情与比较、申购、赎回、持仓和整体收益 | 候选不等于购买；有效评估、产品资格、金额、本人确认与MFA仍需核验 |
| 卡片管理 | 查询、虚拟卡申请、限额／渠道调整、锁卡、解锁、挂失及补卡任务 | 高风险操作须验证；挂失与临时锁卡不同，不能用解锁恢复已挂失卡 |
| 订阅／代扣 | 已有订阅及预计月费查询、扣费关联核对、本人确认取消、模拟扣费和测试恢复 | 不声称完整自动发现所有订阅或向外部渠道推送续费提醒 |
| 跨场景联动 | 多目标任务图及按依赖推进；账单＋订阅、日程＋订阅查询；日程、资金锁定任务、模拟花店／蛋糕店与银行付款 | 示例不是任意复杂需求自动完成的保证；不声称已完整实现赛题生日示例的全自动定期采购 |

另支持语音转文字、历史会话、业务上下文、操作审计、中断与人工接管。当前交付为浏览器Web应用，不将它表述为已完成原生APP／IM渠道接入。详细步骤和可观察判据见 [测试用例](docs/testing/test_cases.md)。

## 主要实现特点

- **受控办理**：自然语言准备任务与可信界面授权分离，查询、本人确认、强验证的边界可见。
- **可干预的规划**：多目标呈现依赖及状态；本人可修改草稿、暂停后续步骤或接管，已完成交易不因对话取消而回滚。
- **事实可核对**：回复使用工具结果；总资产与可支付现金分开，未核实结果不当作成功，也不因超时就断言未执行。
- **配置可解释**：理财规划借用塞勒的心理账户组织思路和Das、马科维茨等研究中的整体协调思路，运用凸优化及持仓约束投影，将个人事实和偏好转成三板块配置；目标产品推荐不调用整体配置模型。

这些是产品与工程层面的实现，不宣称提出新金融理论、复现完整均值方差／多期交易算法，或已证明提高收益、降低真实市场风险。塞勒的2017年诺奖贡献及马科维茨的1990年共同获奖与其2010年合作论文须准确区分。采用范围与必要学术来源见 [理财知识说明](backend/app/knowledge/wealth_planning.md)，算法细节放在独立技术文档中。

## 安全设计原则与参考

针对模型可能误解需求、生成无依据结果或被诱导越权的问题，项目采用服务端权限分级、任务事实核验、本人确认与MFA、关键操作审计、安全锁定及人工接管等措施。模型输出不能替代执行凭证，外部资料和聊天文本不能自行赋予业务权限。

设计参考国家金融监督管理总局2026年6月18日发布的 [《关于银行业保险业人工智能安全开发应用的指导意见》](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1261784&generaltype=1&itemId=4216)（金发〔2026〕8号）所关注的安全治理方向。此处是设计参考，不是逐条合规评价、监管认证或正式上线承诺。具体机制、权限分级和已知风险由技术文档与安全自评报告说明；仓库现有实现依据见 [安全实现说明](docs/agent_security.md)。

## 安装与启动

1. 安装并启动Docker，确认 `docker --version` 和 `docker compose version` 可运行。
2. 解压完整源码，在根目录复制 `.env.example` 为 `.env`，填写自己的DeepSeek API Key。不要覆盖已有配置或提交真实密钥。
3. Windows运行 `start_bank.cmd`；Linux／macOS运行 `bash scripts/start_bank.sh`。首次构建与可选语音模型下载需要网络。
4. 启动器报告成功后访问 [http://localhost:3000/](http://localhost:3000/)，登录并按 [测试用例](docs/testing/test_cases.md) 体验。

详细的逐平台命令、成功判据、演示账号、数据前提、更新停止和排障见 [部署说明](docs/setup/deployment.md)。健康检查通过不等于DeepSeek认证成功。仅重启旧容器不会加载后来修改的源码。

## 数据与体验边界

固定资料包随源码提供，包含806只真实基金（债券242、混合501、权益63）及19个模拟银行产品定义；资格和净值仍须核验，不保证全部产品始终可买。项目评级不等同发行人评级；不提供真实货币基金、主题／高股息筛选或A/C切换。资料升级见 [固定资料与旧库保护](docs/setup/wealth_compact_upgrade.md)。

新申赎使用最近已公布有效NAV，经本人确认和MFA后模拟即时记账；持有期、窗口、额度与资格仍适用，成功后不可撤。收益展示为整体产品口径，不承诺单产品收益查询或未来收益预测。语音只转写，不自动发送或授权，首次下载未就绪不影响文字输入。
