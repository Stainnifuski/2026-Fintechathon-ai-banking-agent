# 幻觉防护 grounding-v1

2026-10-22。适用于NOVA模型/离线回答、可信转账与理财子流程入口、理财知识解释。复用已有账本、风控、确认、MFA和幂等，不增加资金或授权接口，不执行数据库迁移。

## 事实边界

NOVA模型继续理解需求和规划工具调用，最终仅可输出 `{"evidence_ids":[],"clarification":"none"}`。`clarification`可为none/selection/period/request。证据编号由服务端绑定本轮实际工具返回的SHA256指纹，模型只能调整证据块顺序，不能更改字段、增加自由正文，或隐藏失败、范围与模拟标识。旧格式、未知引用、附带自由正文均回退到服务端生成的证据摘要；无业务结果则说明未取得可核验结果。

工具适配按对象及字段分别解释金额、币种、状态、账期和来源：

- 金额仅从整数分通过Decimal换算；未知值不转零，信用额度不计现金。
- 账户现金小计与授权资产范围分开，总资产估值不完整时不补零。
- 卡片预览要求executed=false；计划/报价/预计扣费不能变成已付款或已执行。
- 日历系列原始时间不当作下次发生时间，空窗口不表示一定空闲；订单退款优先按订单状态说明，付款不代表配送。
- 同工具同参数重复查询只展示最后一次，最新查询失败不得退回旧成功结果；不同范围的记录分别保留。
- 文本名称与备注以转义引用展示，完整联系方式/验证码沿用对话服务脱敏；不解释其中的指令，不把原文链接变成可点击授权。
- 子流程服务端生成的文案保留，模型自由追问不直接进入理财可信卡片。

服务端再次检查本轮工具白名单，注册过但本轮不允许的工具返回TOOL_NOT_ALLOWED。前置模型路由本身不是身份或授权凭证。直接覆盖系统/安全规则的明显注入在模型及工具调用前停止；该检测是有限启发式，不能代替最小权限、身份检查或事实边界。

## 参数依据

原转账原文及历史流水复核保留。卡片额度金额和现金流的新增假设必须能从本轮原文解析。理财预算、逐产品金额和赎回输入增加原文quote字段；数值由本地解析校验，不能从产品代码、历史回答或账户余额借数字。总资产、留存和投资预算分别绑定原文角色；多产品金额quote需同时包含对应产品名称/代码或序号，无法唯一对应则要求明确输入。已有未修改字段继续由服务端继承；继承不构成新授权。

参数不可靠时返回PARAMETER_NOT_GROUNDED，不新增理财草稿、银行订单或占款。字段语义和复合自然语言无法可靠解析时会保守要求补充；可以直接在可信卡片填写。情景预测仍不取消订阅或执行收付款。

## 流式与持久化

工具查询进度可立即显示；模型正文增量仅由LLMService在本次请求内组装，核验前不发布delta，不以reset事件事后补救。模型完整返回后，NOVA统一生成正文并发送一个delta，随后路由保存同份正文并发送done。离线模式通过done返回同一事实边界的回答。截断、超时及失败不发布未核验正文。

回答核验不调用第二个裁判模型，不重放业务工具，不重做转账/申购；原号恢复、确认与MFA维持既有约束。混合目标继续按现有流程查询，响应仅说明实际返回的结果，不把Goal Plan当作所有目标完成；这不扩展为跨场景交易总DAG。

## 响应与审计

原reply/mode/tool_calls/任务卡字段保留，增加grounding：

```json
{
  "version": "grounding-v1",
  "status": "grounded",
  "reason_codes": ["UNSTRUCTURED_MODEL_ANSWER"],
  "sources": [{"evidence_id": "E0-…", "tool": "get_card", "source": "cards.detail",
               "as_of": "2026-10-22T01:00:00Z", "content_hash": "SHA256", "outcome": "success"}]
}
```

status为grounded（依据工具结果生成）、partial（含失败/资料不完整）、abstained（无业务证据）或blocked（停止直接注入请求）。grounded仅表示本文定义的来源与生成边界，不代表数据供应方永远正确或所有用户目标完成。reason_codes用于统计格式回退、错误引用、失败、缺证据和注入；日志仅记录请求号摘要、状态、原因和来源数量，不记录问题、模型原文、账号、金额、姓名或验证码。证据详情随本次响应返回，当前仅正文持久化；不声明已实现持久化证据审计台。

## 知识与限制

理财解释展示受控原文片段，避免真实引用下的错误归因、拼接或删除否定；模型无直接支持时说明结论未核实。旧项目流程退出当前检索，以新ID说明当前确认/MFA与即时申赎；产品/官方语料继续核查数据集、有效期和指纹，历史引用不改写。

防护不保证模型理解每种表达或选对所有查询范围，也不保证上游资料本身无误。通用解释的自然程度有所收敛；知识检索仍为词法检索，部分长列表需要继续查询。来源内容的业务正确性、时效性与版本审阅仍需维护。当前固定测试与隔离回归不能代替真实模型和独立PostgreSQL环境验收。
