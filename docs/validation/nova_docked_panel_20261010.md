# NOVA 并排对话面板验证（2026-10-10）

问题：原对话抽屉采用全屏固定遮罩，打开后无法操作银行工作台。

实现：移除 agent-scrim 和悬浮抽屉，NOVA 作为主页面并列的 aside。桌面（宽度大于1100px）业务区与对话区并排，聊天面板贴右、固定视口高度并独立滚动，业务仍使用页面滚动。顶部按钮支持展开/收起并提供 aria-expanded；面板关闭按钮明确为“收起”。业务导航和NOVA快捷导航保留已打开面板，会话不因切换页面清空。

窄屏（1100px及以下）采用上下分区，银行业务和聊天分别滚动；手机底部业务导航保留，布局预留68px。切换业务页时同时重置内部业务滚动和页面滚动。并排时调整概览和账单布局，避免挤压表单。

验证：前端 TypeScript/Vite 构建通过，git diff --check通过；源码检查确认没有NOVA全屏遮罩或点击业务区域关闭面板的事件。未进行浏览器自动化或截图验收，未修改后端工具和授权流程，未重新运行后端测试。

运行中的Docker前端需执行 docker compose up -d --build frontend 后刷新。源码开发使用frontend/npm run dev。本次没有重启已有服务或重建运行容器。
