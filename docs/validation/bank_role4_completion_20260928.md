## 重跑方式

```sh
python -m pytest tests -q
# 额外启用PostgreSQL，使用专用数据库并通过环境变量配置连接串
# BANK_TEST_DATABASE_URL=postgresql+asyncpg://.../bank_test_readiness
python -m pytest tests/integration/test_bank_readiness.py -q
```

未设置BANK_TEST_DATABASE_URL时6项PostgreSQL用例跳过，不能把仅SQLite结果称为PG验收。本次实际设置该变量，107项全通过，无跳过。测试自行创建随机schema并清理。

## 交接注意

- 部署必须先备份、停旧后端，再启动新版自动迁移；不可混跑新旧金额列。回退步骤见[银行交接v0.5](../bank/接口与数据库交接_v0.5.md)。
- HTTP公开元字段保持原单位，内部`amount_fen`为整数分；直接读库的临时代码需要更新，但组员正式集成应使用银行接口。
- 错误展示统一读`detail.message`，程序分支读`detail.code`。超时后原号查询，禁止换号重付。
- 业务审计只记录银行事实；`delegated`不表示风控已通过，3/5号仍需以操作/授权编号关联自己的证据。
- 旧AA批次首次重放可补根记录，但历史原始参与人集合不能完整还原，不能修改参与人后复用旧键。
