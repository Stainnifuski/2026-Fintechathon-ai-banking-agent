# 理财规划现金预算与模型固定比例（2026-10-21）

本轮仅优化正式理财规划。图表、历史缓存、夏普排序、自动刷新全流程和理财 Agent 接入的前序讨论按用户要求暂停。main HEAD 仍为 056b09f，本轮修改未提交、未推送。

## 交互与计算

- 稳健、进取候选分别换批，其他分组和已选产品保留；规划按资格过滤后随机展示，不引入夏普或收益排序。目标产品推荐维持原有代码／类别顺序。
- 在“继续核对所选产品”上方展示非信用卡账户的当前可用现金。本人填写保留现金或本次投资金额之一，另一项按整数分联动；两者之和始终为当前可用现金。未填、负值、超额或超过两位小数时不能继续。
- 请求传递保留现金及页面可用现金，服务端重新核对真实可用金额；金额变化时拒绝旧输入。信用卡额度不能进入预算。
- 模型仍以总资产为分母。设模型原活钱目标 C0、用户保留可用现金 R、不可立即支付的现金及应收 L，则固定现金为 R+L，活钱目标为 max(C0,R+L)。不足活钱目标的部分由合格活钱产品补足；所选产品不足时明确提示补选或提高现金。
- 活钱超过原模型目标时，剩余金额按模型原稳健／进取金额之比分配；整数分尾差保守给稳健，不增加进取风险。风险、资格、持有上限和最终银行预检继续执行。
- 明确现金预算的模型方案禁止服务端手动修订偏好或比例。修改现金／产品后重新生成模型方案。
- 正式规划移除“核对整体配置”编辑区；“整体资产配置”显示板块、当前资产、配置比例、目标金额及具体产品目标。初始基准、允许区间、稳健／进取联动、偏好重算和原 U 提示不再显示。原差额准备、结构化确认、MFA、幂等和即时成交边界保留。
- 新现金方案的已有持仓目标由可信规划服务生成，执行适配允许将其带入最终交易明细；未选择的新产品仍禁止自动采用。没有执行本人账户金融交易。
