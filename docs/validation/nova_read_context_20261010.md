## 真实模型联调

使用项目现有模型配置、独立内存 SQLite 和合成用户/账户/流水完成四个场景。未读取或改变运行数据库，未输出模型密钥或客户数据。

| 问题 | 实际调用工具 | 验证结果 |
|---|---|---|
| 我现在有多少钱可以用？ | get_financial_overview、get_current_time | 合成储蓄账户可用 1234.56 元，占款0元 |
| 当前页面筛选的餐饮消费总额是多少？ | get_current_time、get_bill_analysis | 沿用 2026-09/dining，1521分，共2笔 |
| 这笔流水是什么，金额是多少？ | get_transaction | 使用选中 NOVA-T1，321分，餐饮购买 |
| 列出当前账单的流水明细 | list_transactions | 沿用 2026-09/dining，返回2笔：1200分、321分 |

四个场景均为 mode=model，真实模型选择了预期业务工具，工具结果成功，模型最终金额与合成数据吻合，并说明为模拟银行数据。业务查询结束后内存数据库释放。
