# SenseVoiceSmall 语音输入部署验证

本次在 main `4442c97` 的已有未提交工作上增加语音输入，保留前序 Agent／理财改动。完成本地部署，未提交或推送 GitHub。源码与部署文件可发布；模型、录音、私有配置和运行库不发布。

## 实现与边界

NOVA 录音 → 已登录银行语音代理 → 私有 CPU SenseVoiceSmall → 文字追加到当前输入框。用户检查后手动发送，语音接口不调用 Agent 或业务接口。本人同意、YELLOW 手动确认、RED 确认与 MFA 规则未改。无 TTS、自动发送或持续监听。

固定官方源码、模型版本、CPU torch/torchaudio 和 Python 依赖；禁用模型仓库运行时自动安装依赖及远程代码导入。模型命名卷与银行账本隔离，服务未发布宿主端口。音频在内存解码，接口不持久保存或记录转写正文。45秒／4MB限制、每用户一个请求、代理全局最多两个、识别服务串行。取消、关闭或切换会话丢弃迟到结果。

## 实际验证

- 后端语音专项：20 passed，2.07秒。覆盖登录、上传类型及大小、空数据、错误收敛、超时、并发释放、响应校验与未就绪降级。
- 前端全部现有测试加新增语音辅助测试：105 passed，1.31秒；TypeScript及Vite生产构建通过。没有宣称浏览器组件录音生命周期均由自动测试覆盖。
- 三个Docker镜像构建成功，PowerShell语法、Bash语法及Compose配置检查通过。
- CPU实测：公开中文示例音频和5条本地合成的虚构指令均返回200。5条合成样例的语义、金额3200／1000、基金代码010969及产品名均正确。公开样例没有独立标准答案，不计算识别准确率。暖服务短音频HTTP耗时0.58—0.81秒，不是长音频或并发性能承诺。
- 同一合成金额指令转换为WebM、MP4、OGG后均返回正确文本，耗时分别1.369／0.742／0.822秒。1秒静音、46秒音频和无效音频均返回422。
- 独立临时容器、空模型卷且断网：health返回failed，未伪装ready；恢复为联网独立容器后自动下载固定模型并加载成功，下载日志约26秒，成功识别虚构样例。此为同一已构建镜像的空模型缓存验证，未宣称在另一台全新机器完整验收。临时容器及其专用卷已清理，正式模型卷保留。
