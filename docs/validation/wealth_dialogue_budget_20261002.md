# 理财对话预算与资金事实修复（2026-10-02）

基线main `0410f514fcd92c88fd7ff0012cdde9daf2eb239c`，工作分支codex/feature。用户补充要求：Agent主动查看银行现金与持仓，不要求用户自报已有资产；未指定本次额度时以银行可用现金作为建议预算上限，仍保留本人确认和模拟授权。

## 原因与修复

原演示申购/半仓赎回后，可用现金9500.29元；会话pending仍残留最早20000元预算。泛化clarify请求可以继承完整旧预算并再次创建规划。登录过期还可能保留未核对消息，使不同新消息被幂等保护拦截。

- 完成/执行中方案不作为可修改的旧预算；单产品操作后清理规划pending，保留历史和订单。
- 只有明确规划、修改参数、补充缺项或继续待补需求才进入规划；问候/无关消息不自动重做方案。
- 每轮仍查询银行assets；未指定预算从当前账户available_fen取上限，不把持仓估值、占款和在途当现金。指定额度仍受银行可用现金硬校验。
- 将bank_available_cash/user_specified来源存入方案request，页面展示生成时依据；超额提示列出预算和可用现金。模型不得把历史数字或查询事实伪装为用户明确金额。
- 提供原消息编号重试入口，不盲目清除未核对请求或重置账本。
