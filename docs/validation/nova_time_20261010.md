## 真实模型联调

使用项目现有配置，通过 nova.chat 实际发送“现在北京时间几点？”。沙箱内请求报 MODEL_NETWORK_ERROR，获得网络权限后重跑成功。未输出密钥或外部原始响应。

模型实际调用 get_current_time，服务端工具返回：

```json
{
  "server_time_utc": "2026-10-10T16:18:33.121110Z",
  "timezone": "Asia/Shanghai",
  "local_time": "2026-10-11T00:18:33+08:00"
}
```

模型最终回答包含“2026年10月11日（星期日）00:18:33”和 Asia/Shanghai（UTC+8），与工具结果吻合。运行模式为 model，执行摘要包含一次 get_current_time 调用。此记录验证真实服务端循环；浏览器交互未做自动化验收，前端验证为构建检查。
