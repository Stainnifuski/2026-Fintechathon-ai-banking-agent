# 真实净值时效与同日批次成本（2026-10-18）

## 实际问题

只读核对本人近期成交发现，000039于10月18日申购1000元时使用9月30日净值5.5793，形成179.2339份；同日赎回用后来观察到的10月16日净值4.9205，到账881.92元，费用为0。118.08元差额来自不同净值日期，不能描述成周日新产生的市场涨跌。真实基金的固定离线报价原先绕过过期检查，行情失败或尚未补录时也可能参与即时成交。

另一问题是同日FIFO按批次哈希编号排序，并未保证实际申购先后。部分赎回会错误选择同日较晚买入的批次，影响剩余成本及已实现收益分配。

## 修复

- 真实基金交易统一校验当前所需净值日期与实际可见性。按项目北京时间18:00复核界点和已验证交易日历确定所需日期，周末和休市日不推进；未取得所需净值返回NAV_UPDATE_REQUIRED，明确原因和稍后重试/改选办法，不用过旧离线报价成交。
- 正常估值仍可补录后来观察到的历史行情；不伪造周末净值，不改历史成交、份额、成本或现金。搜索、换批仍使用本地目录与已有报价，不新增外部请求，也不将过期报价误当成产品身份失效。
- FIFO按取得日期、原始受理时间、批次ID排序。计算仍按批次扣份额和成本，全赎释放成本尾差；不新增冗余的汇总成本净值字段。
- 按用户要求，持仓主表新增项只标“最新净值”，不追加净值日期。底层日期、可见时间、成交、费用和批次记录继续保留。多次买入需加权的是单位成本，而非市场单位净值；单位成本=剩余总成本/剩余份额。
