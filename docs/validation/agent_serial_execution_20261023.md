## 实现

- 一句话最多8个目标，原文片段校验、DAG稳定拓扑排序、本人会话加密持久队列和逐项状态展示；暂不提供改序。
- 只启动当前目标；对象选择、正式问卷、手动确认、MFA或未成交均等待。终态由原银行状态判定。规划SELL完成不等于整项完成，独立BUY仍须本人确认、第二次MFA及实际成交。
- 当前卡片的自然语言补充沿用当前任务。路由不得因历史中的多目标重新生成队列；下层只接受单个当前意图，不能创建并行新任务。转账模型另指定chat_task_id也不能越过当前焦点。
- CAS和运行租约避免重入；失联停止并核对原任务，不自动重放未知操作。等待轮询只读、不更新版本、不调用模型或行情。失败保留已成交操作，未支出资金留在账本现金。
- 跨场景复用同一执行器，范围为现有理财/转账/卡片预览和账户、账单、订阅、日历、店铺查询工具。未接通的订阅扣费、店铺付款等不宣称可由队列执行。接口见`docs/contracts/agent_serial_execution.md`。
