## 用例覆盖

- 列表按用户隔离、未登录401、他人卡片404。
- 权限级别取自共享权限表：申请/限额 yellow，解锁/挂失/调额 red。
- 黄色：预览不改变银行数据；错误摘要拒绝；确认后受理，重复确认返回同一张虚拟卡；信用账户、他人账户不能开虚拟卡；每账户3张上限。
- 限额：超上限、单笔高于单日、未变化、缺字段、多余字段、超两位小数均拒绝；成功后版本递增。
- 红色：确认后停在 AWAITING_MFA 且卡片未变；未绑定验证器、错误码、同时间步重放均拒绝；正确 TOTP 后受理；审计含 red 验证记录和银行 delegated 受理记录。
- 锁定卡不能调额；超核定上限、借记卡调额拒绝。
- 挂失为终态，之后解锁/挂失/改限额均 CARD_LOST。
- 预览后卡片版本变化：确认时 STALE_STATE_VERSION，操作记 FAILED，不以新状态执行。
- 同号同参幂等、同号异参冲突、取消后不能确认、过期记 EXPIRED。
- 连续5次错误验证码终止授权，之后正确验证码也不能执行。
