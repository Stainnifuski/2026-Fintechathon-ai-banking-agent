# 知识与引用 v1.2

离线回归40篇，版本`knowledge-v12-1`：30个不同产品家族的原创规则说明、5篇项目流程/安全说明、5篇官方资料的原创摘要（CPI/PPI/M1-M2/PMI/LPR）。完整清单由`wealth_knowledge.documents(generate()['products'])`可重现，不复制受限原文。

每篇有document_id、主题、来源类型/URL、已知发布时间或null、获取时间、有效范围、内容指纹、版本与授权说明。官方摘要仅解释指标定义和口径，不暗示官方认可产品。来源URL在代码OFFICIAL清单中；尚未核实的时间为空。

中文双字切分加ASCII词，标题加权，默认top4、最多6篇、每篇片段1600字符，明确是词法检索而非预训练/微调。无匹配时资料不足，不添虚构引用。解释模型仅选择引用和摘录；最终回答展示来源完整受控片段，保留条件、否定、产品身份及数值上下文，不采用自由改写结论。伪造引用返回资料不足；模型结论无直接支持时明确说明未核实，再展示相关原文。文档内容没有签发授权、修改风险或调用管理员的权限。

2026-10-22 起，当前检索排除旧 `source_type=project` 流程说明，以 `project-20261022-grounding-v1` 的5篇当前项目说明替代，ID为 `KP-20261022-*`。当前说明是代码内受版本控制的只读语料，不在查询时写库；旧库内容与历史引用不修改。当前说明覆盖本人确认、统一TOTP/短信MFA及模拟即时申赎，不能用旧点击授权／等待结算说明解释当前行为。产品语料仍按数据集、有效时间及内容指纹过滤；内容被改写但指纹未更新的记录不参与检索。历史40/50篇是对应旧版本记录，不代表当前运行库语料数。详见 [幻觉防护](../security/hallucination_guard.md)。

可选`requirements-knowledge.txt`固定llama-index-core 0.14.25；`optional_nodes`显式构造TextNode，不启用远程embedding或大型索引。默认未使用语义嵌入；不把可选组件称完整Agent框架。

更新语料须变更版本和document_id、复查URL/有效时间/内容指纹，重新导入；旧证据保留。初始化只补缺，不能偷偷修改历史引用。100题中25题核对实际内容与结论支持；真实模型引用与缺证据样例单独记录。Codex抽核不代表团队人工签字。
