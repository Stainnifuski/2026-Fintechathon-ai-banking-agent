# 推荐与净值详情

推荐行展示产品名称、类别、含费申购金额、占本次确认预算比例、简短理由及详情入口。横向条形以本次预算为分母，未投入现金单列；费用已包含在支出，不重复扣除。账户剩余可用现金不参加预算占比。部分采用或减额后服务端重新计算现金和费用估算；最终以可信预检为准。

`GET /api/v1/wealth/products/{product_id}/detail?period=1m|3m|1y`使用本人当前研究范围，默认一年。服务端按UTC发布瞬时和北京时间业务日过滤，未来文件价格不会传给浏览器。最新已发布净值独立于图的观察窗口。详情展示真实基金数据/模拟产品身份、风险、起购、持有期、普通到账工作日和快赎服务窗口与额度。官方说明书引用不表示在售或收益承诺。

## 三项描述指标

同一日历月窗口、同一组实际已发布估值点：

- 净值涨跌幅：`(末值/首值-1)*100`，至少两个点。
- 最大回撤：`max(1-当日净值/截至该日峰值)*100`，非负，至少两个点。
- 简单年化波动率：有效相邻估值日的简单收益率，样本标准差（分母n-1）乘`√252*100`，至少20个有效收益率。缺失预期估值日或异常跳变时不展示为正常波动率。

服务端使用Decimal计算，输出两位显示小数，不改变账务精度；返回指标版本、窗口、数据/日历版本、as_of、点数和质量原因。目前按请求计算，不复用跨时点缓存。周末carry不计为新收益观测；空点、单点和短历史不补成立前价格。真实货币基金收益率不是单位净值，明确显示缺失原因，不伪造净值指标。真实单位净值指标不等于含分红总回报，模拟历史不代表预测或客户账户收益。
