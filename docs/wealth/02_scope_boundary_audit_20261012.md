# 02 开发范围复核：公共改动与测试显示｜2026-10-12

用户指出 3012 首页出现“B6 隔离验收（固定方案）”，要求核对是否改写队友模块及类似越界。暂停后续开发，检查当前功能分支相对本地 origin/main 的完整文件列表，并读取理财目录以外的源码差异。此处基线为此前已合入的 main，不声明本轮重新抓取远端。

## 查明并修正的两处显示干扰

1. 首页欢迎句与 main 一致，仍为 `{user.name}，今天的财务状态很清晰。`。问题来自 tests/browser/wealth_b6_server.py 为虚构 U1 设置了长测试名称，首页、头像、NOVA 称呼都正常消费同一姓名，导致测试术语出现在业务欢迎语中。本轮测试种子恢复 U1 张三/U2 李四；隔离性质不再借姓名表达。
2. App.tsx 曾新增一个仅 DEV 且 VITE_B6_BROWSER_TEST=true 的测试横条，但没有限制当前页面，因此在整个隔离前端各模块都显示。本轮限定 appView=banking 且 bankingSection=wealth，测试说明留在理财页，不在首页/转账/账单/卡片/订阅/生活服务显示。

两个运行中的 B6 临时库只更正虚构用户的 name。操作前验证路径在仓库 .tmp、文件名 browser_bank.db、用户 ID/手机号匹配固定夹具且卡号 b6-mock-*，再更新显示名称；没有修改金额、订单、持仓、角色、验证码或日常库。旧登录页面缓存的姓名通过退出/重新登录刷新。普通 seed/认证/首页欢迎句无需为此添加替代逻辑。

“功能主要在理财模块”不能简单等同于“只能修改理财目录”：02 自身含首页总资产、账单边界等公共要求。后续公共文件改动应逐项列明对应条款或此前明确授权，避免测试术语进入其他页面；不会以一般‘体验优化’理由扩展队友功能。
