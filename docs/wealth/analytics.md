# 确定性分析口径 v1.2

金额整数分、净值和份额Decimal；图表可转浮点，账务禁止float。公式版本`analytics-v12-1`。先按截止日/可用时间过滤，再选1月30日、3月90日、1年365日或成立以来窗口。缺数不补零、不前向填充；短历史给原因。

- 单位净值变动：末/初−1；只有明确核实分红才按每日(nav+dividend)/前nav再投资连乘。合成产品已明确零分红；真实产品不称总回报。
- 年化：累计指数^(365/实际日数)−1，跨度不足365天不展示。
- 最大回撤：max(1−累计指数/此前峰值)，样本不足2条不可算。
- 波动：至少20个观测收益，样本方差（n−1）平方根×sqrt(252)。缺日只用观测对，不声称填满真实交易日历。
- 相关系数：共同日期收益的中心化协方差/标准差；至少31共同价格观测，零方差返回原因。2–3产品曲线和指标均采用共同窗口，不能拿不同成立期直接比。
- 申购费与赎回阶梯由银行规则计算；年度费用已含模拟净值，不再次扣费。估算不等于最终计价。
- 流动性按版本化日历计算确认、最低持有和现金到账；推荐先排风险、暂停、非开放日、期限、缺净值、过旧数据和最低/最高金额，再稳定排序。
- 新资金方案最多5笔，家族不重复，单家族不超过可投入预算60%。v1.2缺类别时保留该份现金，不把剩余风险类别强行放大；拒绝净值亏损者保留现金。

资产按当前资金上下文查询，A/C合并家族集中度；无真实穿透持仓则显示unknown。`historical_hypothesis`用当前金额作为假设起点配置、固定份额重建共同日期曲线，不是假称实际持仓收益，不含申赎费/后续现金流，也不把存入资金当回报。缺任何组件不给组合指标。实际时间加权/资金加权回报暂无完整可核实现金流序列，明确不可计算。

金样本与100题事实/规则评测在`tests/unit/test_wealth_v12_evaluation.py`，组合、开放日、宏观日期补充在`tests/integration/test_wealth_sync.py`。
