# 理财规划：新增现金与必要减持

2026-10-21。本说明覆盖旧版“重新分配全部持仓”的规划行为；目标产品推荐不使用此配置模型。规划候选仍随机展示，稳健／进取各自换批，活钱不提供换批。不接夏普排序或自然语言执行 Agent。

当前可用现金 C 不含信用卡额度；H 为当前全部持仓市值。保留现金 R、本次投资 I、总投资 V 支持任选一个输入，按分精确计算 `R + I = C`、`V = H + I`。合法范围为 R/I 在 0…C、V 在 H…H+C。估值未完成或现金已变化不能继续。I 是新增现金预算，必要赎回后实际申购总额可包含赎回所得，二者不能混称。

表格的“配置比例”和“目标金额”表示模型建议；下方“本次实际执行”列出具体产品当前→目标、拟申购或拟赎回金额，不显示执行比例。模型建议和执行目标分别由服务端 `planning.suggested_amounts_fen` 与原 `buckets/advised_positions` 返回。

旧持仓默认保留，高于模型建议不自动卖出。必要减持只由风险等级硬约束触发：R1 全活钱；R2—R5 活钱至少10%，进取占非活钱资产分别不超过25%/50%/75%/100%。现金、冻结现金和应收的口径保持；冻结／应收不充当可立即支付现金。所需活钱不足时选择活钱产品补足。满足限制后，新增资金尽量贴近模型推荐的稳健／进取关系。

需要减持的板块按所有现有产品市值比例分摊到分，跨账户仍按市值比例分摊。新投入只分配给本人所选且当前合格的具体产品。持有期、可赎份额、最低金额、窗口、费用和权限继续由银行预检；不能以一个产品不可赎为由擅自增加另一个产品的赎回。费用按已知规则保守预留对进取上限的影响，成交后仍重新核对；未知费用或持仓权限不推断为可用。

执行分两阶段：

1. 原 prepare 生成 SELL 明细，预览不扣款、不占款。本人确认全部赎回明细、第一次统一 MFA 后，按原号即时赎回。
2. POST `/api/v1/wealth/plans/{execution_id}/continue-purchase`，请求 `{version}`。只处理本人增量规划 SELL。回查每笔原操作，全部 SETTLED 才核对账户现金、份额与真实净到账。未知、部分失败、暂停、接管和额外资金／持仓变动均阻断。
3. 在当前资产事实下保留原 R、原选品，重新调用规划，再 prepare 为全新 BUY 执行方案。返回 `{plan, prepared}`。不复制旧确认、授权或 MFA。本人阅读新明细，独立确认并第二次 MFA 后才申购。

同一 SELL 的成功接续结果保存于原执行记录，重试返回同一个 BUY，不重复提交。当前实现沿用单服务实例内的规划存储与接续锁；没有宣称多实例分布式规划存储。若费用、行情或规则变化导致仍需再次赎回，停止接续并提示重新规划，已经到账资金保持现金。关闭页面或接续失败均不会自动执行申购。

固定资料不受此变化影响，无需重打806离线包；运行账本、密钥和缓存不分发。验证范围见同日验证记录，不能把隔离测试称作本人金融交易。
