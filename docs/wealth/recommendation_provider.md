# 理财推荐provider契约

当前默认`DeterministicRuleProvider`，`provider_id=mock-allocation-v1`，版本1；复用原分配权重和费用/流动性排序，不引入新模型算法。

服务通过`WEALTH_RECOMMENDATION_PROVIDER`和显式`register_provider`选择实现。实现`recommend(inputs)`与`research(inputs)`；研究返回无金额的条件候选，可执行配置返回金额、预算、费用、未分配现金、目标/实际类别占比、理由代码与证据。实现不得接收数据库session、密钥或本人授权。

输入包括：已核对可用现金及as_of、正式评估上限、版本化需求字段、产品及规则/日历/NAV版本、当前敞口；历史特征不被当前算法使用，显式标记缺失。目标、期限、到账要求是独立约束，具体支出用途可未提及。

目标的适配仅降低候选风险上限：减少波动/保值不高于R2，兼顾不高于R3，增长沿用正式评估上限；“保值”不代表保本承诺。立即到账只保留提供快赎且无持有期的产品；可等明确工作日数时限制普通到账工作日且排除锁定产品。未确定的条件不被默认填值，改走有条件研究。产品查询/比较无需先回答上述问题。

推荐服务独立检查provider身份、schema、数据时点及版本、资格、风险、流动性、最低金额、家庭去重、60%集中约束、金额合计、账户剩余现金、预算保留与尾款。无效结果拒绝，不裁剪参数后伪装有效。金额是包含申购费的总支出，费用另列但不重复扣除；占比分母为确认预算，账户剩余现金不参与该100%预算图。

目前完成接口、规则适配、校验和单元/双库方案验证；推荐前端条形图及详情将在本轮后续实现。实际证据见本轮固定验收记录。

## 2026-10-04总投资金额模式

allocation.full_investment=true时复用默认规则的候选、风险、费用排序、家族去重及60%限额，再在同约束内分配剩余金额，最多仍原max_items。固定金额是总投资额，不默认拆出现金。无法全额分配返回unallocated_reason；支付能力、必要留存和产品限制不放宽。已知偏好仍适配；未知期限365天是内部筛选窗口，request.horizon_policy明确不作为用户回答。既有调用未传full_investment维持预算留存模式。
