# 理财模拟安全自评与边界

本文件是代码自评，不是法律意见、金融资质证明或生产安全认证。产品、资金、画像、问卷与外部资产均限虚构数据。任务书列出的监管来源作为真实上线审查线索；本次不把用户确认等同免责或真实电子签约。

## AI可用性与限制

理财模块只运行明确标注的有限离线模式，不调用付费模型或读取真实资料。支持客观产品、2—3产品ID对比、推荐候选、预算/期限/保留资金方案、单产品金额申购意图、全部/一半/目标金额估算赎回。命令卡仍必须由本人核对、评估、确认和验证。未理解的表达追问或返回明确错误，不猜测执行。“替我评估”“提高等级”“验证码”“绕过规则”拒绝；不保存凭据消息。

TOOL_SCHEMAS为严格只读/预览适配契约，`checked_explanation`拒绝不存在的产品或非白名单理由。当前展示使用确定性模板；没有声称完成真实大模型质量、付费供应商超时或远程模型故障联调。有限模式下刷新恢复、断网未知、原号核对已测试。真正接模型时只可传必要脱敏模拟事实，解释失败仍返回模板，不授写工具。

## 模拟简化

- 可变净值份额制，不实现真实现金类基金收益结转、分红再投、税务、快赎或真实行情。固定模拟休市日，不是交易所真实完整日历。2026—2027样本NAV用完或缺价必须等待人工补充新版本数据，不能自填价格。
- 五档量表和分类目标比例是版本化比赛规则，未经过专业效度验证。单月已申报支出保留为明确保守规则，未知支出不凭空估算；画像/目标仅虚构规划，不是自动理财委托。
- 外部仅CNY，来源用户手填、保留更新时间，不接实际外部账户。用途标签不会冻结所有应急资金，交易后标签需重新核对，不保证未来金额。
- 每个用户为一个隔离主体，无跨机构多租户生产身份系统；后台只结算既有已授权订单，不无人调仓。独立演示验收允许虚构问卷/验证码夹具，不可替真实用户填写、同意或验证。

## 真实上线尚需专门审查

产品/销售/组合建议资质、专业适当性量表、真实电子签约、销售留痕留存、投资者保护、产品类别/费用合规、真实营业日与NAV源；个人金融资料处理依据、单独同意、跨境与供应商审查。基础项目仍用演示TOTP明文种子存储与演示身份密码，真实部署需要加密密钥管理、集中网关限流、认证强化、安全监测、留存/清理政策及外部独立安全审查；本任务未把这些写成已完成生产能力。

## 数据清除与回退

不提供普通删除用户来清金融记录。隔离演示库、数据库副本、临时码和备份不进Git；用停机备份/空业务回退明确流程。有业务时禁止删理财表或退旧代码忽略占款。审计和账务保留与演示清除分别处理，不凭一条监管期限设全系统统一保留期。

## 演示验证例外（2026-10-01用户明确授权）

独立虚构库允许模拟点击验证，无验证码。默认关闭、实际库名限制、本人适当性和订单绑定不变；记录SIMULATED_CLICK、simulated=true、replacement_required=true，审计result=simulated及订单来源。真实模式不能消费未受理模拟授权。此前逐笔TOTP流程描述仍适用于正式模式；模拟模式不是生产强验证证明。

统一一次确认不省略逐笔记录；整份确认失效或遗漏时原子拒绝。以后必须按handoff.md替换提供者并创建新真实授权，不把历史演示记录改写为真实验证。
