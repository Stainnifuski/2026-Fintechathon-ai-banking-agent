## 差异与复用

现有现金整数分、账户锁、事务审计、登录、TOTP 防重放、内部 HTTP 银行接口继续使用。现有转账授权表带转账操作外键，理财使用独立版本化授权记录，复用安全策略，不伪装成双方账户转账。新增账单契约仅将 purchase/subscription 算消费；理财使用 investment_purchase/investment_redemption 类型，单列资金流，不纳入日常消费。

## 默认值

CNY；8个虚构产品（3理财、5开放式基金）；净值8位小数，份额4位小数，以字符串传输；现金整数分。外部资产仅诊断，不可扣款。9题、5档、365天有效期，单日2次/滚动12个月8次；只支持成年完全民事行为能力模拟用户。确定性规则推荐，模型仅解释；默认离线，不发付费调用。

组合最多5笔；现金保留合法；纯购买受理原子占款。部分失败暂停未提交，核对在途，不逆向回滚成功订单。赎回按合格批次FIFO，到账后买入必须重新预览、本人确认、强验证。安全时间使用真实UTC；模拟业务时间仅管理员隔离演示，不能延长10分钟授权。

## 分层与影响范围

- `domain/wealth*`：精度、费用、交易日历、状态与规则。
- `models/wealth*`、`services/bank/wealth*`：银行产品、净值、订单、批次、占款、结算、账务与事实审计。
- `integrations/wealth*`、`services/orchestration/wealth*`：HTTP银行契约、计划版本、依赖与恢复；不导入银行ORM。
- `integrations/*authorization*`：确认、强验证与摘要绑定，服务端适当性硬限制。
- `services/ai/wealth*`、`routers/wealth*`、前端组件：受控意图、解释、可信表单，共用服务。
- 既有转账/订阅扣款统一检查账面余额减有效占款；AA最终付款复用转账，保留现有权限接口。
