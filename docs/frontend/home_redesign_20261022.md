桌面默认展示NOVA大屏，收起后展示左侧财务概要与右侧全高NOVA侧栏。两模式共用同一个对话组件、输入与任务树，不通过关闭再打开来切换。大屏时保留底层业务页及所选对象，业务页上下文通过“参考工作台”提示；点击业务导航则显示对应业务页及侧边对话。窄屏沿用原业务优先、可开关对话的布局，不声明设计了新手机版。

- 顶部“新建/历史对话”和模式按钮统一为深色白字胶囊；模式按钮精确为“展开 NOVA / 收起 NOVA”。旧紫色224px长文案要求已被用户后续决定取代。

- 总资产恢复旧版深蓝至蓝紫渐变及圆弧背景，保留新版明细布局。正常状态隐藏手动资产刷新，沿用每5秒自动查询与业务变化刷新；失败保留“重试”，加载时显示“正在重试…”。“刷新账单”独立保留。
- 左导航保留较深的功能色块；同一功能入口使用一致色系。首页跳转和对话功能提示采用柔和浅底、深色文字、圆润胶囊。
- 订阅名称及“更多示例”采用近黑色 `#172033`；活期账户图示蓝色、信用账户金色，并保留内部线条。
- 发送按钮为正圆：空输入/禁用浅紫 `#b8abd9`，可发送深紫 `#49318c`，悬停 `#38216f`，保留焦点样式。输入提示为“输入你的问题和需求”。

## 财务概要与数据口径

| 区域 | 最终实现与边界 |
|---|---|
| 总资产 | 沿用 `/api/v1/wealth/asset-summary` 和原AssetSummaryStore，保留授权、业务时间/查询时间及缺估值提示。分只换算一次，失败不伪装成0。信用余额不计入总资产。 |
| 账户与卡片 | 原accounts与 `/api/v1/cards` 按account_id关联；余额、尾号、卡片状态来自接口，信用总授信/已用/可用分别读真实字段，不把信用余额当可用额度。窄卡片使用自适应布局，信用字段整组换行。 |
| 本月支出 | 读取 `/system/time` 确定北京月份，再查询 `/bills/analysis`。列出全部正额消费分类；比例条按分类金额合计计算，悬停显示金额/百分比；消费原额、退款、净消费分别展示，排除转账和理财现金流。 |
| 跨月与刷新 | 页面可见时每60秒复核服务端月份，focus/visibilitychange再次检查；跨月重查，同月不重复查报告；保留手动刷新和失败重试。 |
| 订阅 | 仅列ACTIVE，按next_charge_at排序，展示原计划日期和金额；已有过期计划日期不擅自推算为未来，不触发扣费。 |
| 完整业务入口 | 首页不再放旧三指标及最近流水卡；完整资金流水/收款申请在“转账与收款”，消费详情在“账单洞察”。保留卡片、订阅、理财、联系人/定时及生活服务原能力和商户分流。 |

没有复制设计示意余额、消费、订阅日期或演示回复；没有新增缺少来源的总负债、净资产、跨行资产。吉祥物和新人工接管能力未实施，不伪造接管成功。
