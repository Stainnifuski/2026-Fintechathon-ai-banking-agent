## 用户可见变化

1. NOVA不再在消息上方堆放长欢迎页；空会话只给简短提示，输入区提供上下文优先的快捷问题和可折叠更多示例。历史／新建入口折叠到标题旁，输入框提示精简。服务端会话历史、任务卡、请求编号和幂等重试兼容保留。
2. 首页与业务标题改为直接名称，移除无事实支撑的宣传性判断，区分订阅计划和实际扣款。卡片可信核对和转账待确认提示继续保留，界面精简不替代本人确认或验证码。
3. 登录页采用批准的白底巨型“NOVA／你的银行智能体”和七个彩色模块。悬停、聚焦和输入时装饰向两侧散开；窄屏保留四个装饰，减少动画偏好关闭位移／漂浮。登录、注册、错误、密码显示和折叠演示账号帮助接回原逻辑；初始账号密码为空，防重复提交。
4. Vite按工作树隔离优化缓存，并预构建ECharts各入口，修复共享依赖缓存导致的账单懒加载白屏。未改变账单数据或接口。

## 队友如何更新

保留各自未提交改动、`.env`和数据库，正常获取并整合最新main。使用当前源码根目录的[统一运行指南](../../运行指南.md)，正式入口仍为`http://localhost:3000/`，前后端需来自同一版本。不要把本机3100／8110独立预览当作正式部署地址。

- Docker：按运行指南重新构建同份源码的前后端，不能只刷新页面或重启旧镜像；不要删卷或覆盖账本。
- 原生开发：使用原环境配置、锁定依赖和当前源码；前端`npm run build`验证，开发时依照运行指南配置代理。锁文件无变动，已有匹配依赖不要求因本次重新安装。
- 登录页登录成功沿用现有工作台；演示账号只在当前库已有种子时适用，不能替代队友自己的账号。
- 账单白屏修复后应刷新旧标签，避免继续使用已污染的旧模块图。缓存是本地忽略产物，不随提交分发。

本次发布仅更新GitHub源码，不部署或重启main服务；现有运行页不会因远端合并自动升级。
