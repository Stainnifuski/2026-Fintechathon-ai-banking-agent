# NOVA 使用指南

更新：2026-10-10。NOVA 已接通只读 Agent Loop，可以在顶部“问 NOVA”面板中查询本人银行与生活服务信息。实际交易仍在对应业务工作台完成。

## 打开、切换和选择

登录普通银行用户后点击“问 NOVA”。桌面端在右侧与业务页面并排显示；宽度1100px及以下采用上下分区，各自滚动。打开时可继续操作页面，点击顶部按钮或面板“×”收起；切换业务页面保持对话。回答支持标题、加粗、列表和可横向滚动的表格。

聊天仅保存在前端内存，收起保留，刷新或退出登录清空。请求使用发送时的页面状态，查询记录可展开核对来源和关键事实；页面加载时间与工具查询时间可能不同。

| 页面操作 | 可以问NOVA |
|---|---|
| 首页或任意页面 | “现在北京时间几点？”“可用资金有多少？” |
| 账单页应用月份/年份、账户或分类 | “解释当前筛选的账单”“请帮我查看今年的账单情况” |
| 卡片页点击“选择供 NOVA 查询” | “这张卡的状态和限额是多少？” |
| 订阅页点击“选择供 NOVA 查询” | “这个订阅什么时候扣费？” |
| 任意页面查询卡片/订阅 | “我的信用卡额度是多少？”“我的订阅每月预计要花多少钱？” |
| 流水行点击“选择这笔” | “这笔流水是什么？” |
| 生活服务 → 日历，选择日期 | “这一天有什么规划？” |
| 日历活动点击“选择这个活动” | “这个活动什么时候举行，在哪里？” |
| 任意页面，明确日期或活动名 | “明天有什么规划？”“项目答辩什么时候举行？”“下次团队例会什么时候举行？” |
| 花店/蛋糕店，打开店铺 | “这家店有哪些商品？”“查看我的店铺订单” |
| 店铺商品点击“选择商品问 NOVA”，调整数量 | “这个商品我选的数量总共多少钱？” |
| 店铺订单点击“选择订单问 NOVA” | “这个订单付款了吗？” |
| 任意页面，明确店铺和条件 | “鲜花店100元以内有什么花？”“蛋糕店有哪些商品？” |

账单上下文取当前已应用报告，而非尚未提交的筛选表单。“今年/本月”等现实相对时间按当前时间解释，“当前筛选/这天/这个商品”按页面选择解释。日历重复活动需要ID与实际开始时间共同定位。同名活动多项时先选择；没有选中对象时请提供名称、日期或ID，不会默认猜第一项。

## 当前查询范围

后端当前注册16个工具：

| 信息 | 工具 | 数据与口径 |
|---|---|---|
| 现实时间 | get_current_time | 默认北京时间，可指定IANA时区 |
| 本人账户概览 | get_financial_overview | 模拟银行；现金总额仅汇总savings，与首页一致 |
| 月度/年度账单 | get_bill_analysis | 模拟银行；完整统计不受流水分页影响 |
| 已完成流水列表/详情 | list_transactions、get_transaction | 模拟银行；本人账户归属校验 |
| 本人卡片列表/详情 | list_cards、get_card | 模拟银行；脱敏卡号、状态、限额/上限，信用额度不等于现金 |
| 本人订阅列表/详情 | list_subscriptions、get_subscription | 模拟银行；周期金额、计划扣费、取消状态，汇总为预计月费而非实际扣款 |
| 本人日历范围/名称搜索/详情 | list_calendar_events、search_calendar_events、get_calendar_event | 本人保存日历，来源user_calendar；全天按原日期，重复规则按窗口展开 |
| 两店商品列表/详情报价 | list_shop_products、get_shop_product | 模拟店铺；当前目录价，数量报价不表示下单 |
| 本人店铺订单列表/详情 | list_shop_orders、get_shop_order | 模拟店铺；下单价格快照，银行付款事实的只读状态投影 |

日历查询范围最多62天，重复活动详情默认未来30天，窗口内无发生只表示该窗口没有安排。名称搜索检索全部保存的标题/地点，不受当前月份限制。列表分页并说明总数；长活动备注可分段读取。

店铺付款状态按银行记录投影，不写回订单或账务。COMPLETED表示模拟银行付款成功，不表示配送；REFUNDED表示整单退款。页面尚未刷新时可能仍显示旧状态，可刷新店铺页面核对。缺付款记录时不能确认已支付。商品库存、配送、营业时间、真实门店地址和优惠未提供。

卡片及订阅已接入只读查询，理财专用工具和转账执行尚未接入。NOVA不下单、扣款、退款、不签发授权、不创建/删除日程、不发送提醒；相关操作使用已有工作台。当前只读Loop不等于跨场景交易总DAG。

订阅列表默认包含已取消项；预计月费仅汇总筛选后所有分页的生效、月度、人民币订阅，不受当前页大小影响。计划扣费时间不表示已扣款或一定自动执行。卡片查询不提供剩余信用额度。

接口与字段分别见 [基础工具与页面上下文](../contracts/NOVA页面上下文与只读工具_API_v0.1.md)、[时间](../contracts/NOVA时间查询_API_v0.1.md)、[日历](../contracts/NOVA日历查询_API_v0.1.md)、[店铺](../contracts/NOVA店铺查询_API_v0.1.md)、[卡片/订阅](../contracts/NOVA卡片与订阅查询_API_v0.1.md)。

## 模型与离线模式

共用根目录.env的LLM_*，默认服务只需配置一次LLM_API_KEY；LLM_MODE=auto有有效配置时启用模型，无配置时使用有限离线规则，offline全局关闭外部模型。LLM_MODE=model要求有效配置。详细配置见 [统一模型配置](model_configuration.md)。不要把密钥写入前端或提交到仓库。

离线支持有限的北京时间、资金/账单、常用日历日期/名称、卡片/订阅列表与页面选中详情、当前店铺目录/选中商品报价/本人订单查询，页面明确标记“离线规则”。复杂表达、跨轮推理、其他时区时间、商品价格条件筛选和两店比较需要模型。配置了模型但调用失败时会显示错误，不自动伪装成离线成功。

每次请求最多4轮模型调用，每轮最多4个工具调用，整体90秒；每轮还受LLM_TIMEOUT限制。NOVA输出预算4096 token，受LLM_MAX_TOKENS上限约束。默认报告先摘要，更多细节可分项追问。

## 更新和排查

本轮NOVA扩展没有数据库迁移。保留已有.env和数据库；Docker部署同步源码后更新前后端：

```bash
docker compose up -d --build backend frontend
```

刷新页面。仅前端样式变化可以单独重建frontend；仅后端预算/工具变化可以单独重建backend。修改.env后需重新创建后端以更新注入环境，方式见模型配置文档。3010/8010独立演示环境要更新其实际运行服务，不混用数据库或通过删卷更新页面。

源码开发需要重启后端，在frontend下安装锁定依赖并启动开发服务：

```bash
npm ci
npm run dev
```

| 现象 | 核对方式 |
|---|---|
| 仍显示导航原型、禁用输入或旧遮罩 | 确认实际运行前端构建已更新；本轮工具接入还需要更新后端 |
| “离线规则”不支持复杂提问 | 检查LLM_MODE及有效模型配置，重启/重新创建后端；不显示密钥排查 |
| MODEL_OUTPUT_INCOMPLETE | 模型未完整生成；length提示输出长度限制，其他原因提示中断。检查低于默认4096的自定义LLM_MAX_TOKENS，或分项查询。后端日志保留原因和预算，不保留原始回答 |
| MODEL_TIMEOUT或AGENT_TIMEOUT | 分别为单轮模型时限和整体时限；保留输入后可手动重发，不自动重复请求 |
| AGENT_STEP_LIMIT | 模型未在4轮内结束；明确对象/范围或拆分问题 |
| 选中对象未找到 | 可能未选择、已删除/改期、跨店选择或无权访问；刷新并重新选择，不通过聊天指定其他用户身份 |
| 日历窗口没有安排 | 检查日期/时区或指定其他范围；不代表所有日期都没有活动，也不代表一定空闲 |
| 订单状态与旧页面不同 | 检查当前店铺和查询时间，刷新页面；NOVA读取付款状态而不持久化对账 |
